CORS Hunter 本地验证

请按靶场启动输出中的 API 地址访问 /api/reflect。README 示例使用 18000/18001，脚本默认使用 8000/8001。先让请求经过 Burp，并将 API 加入 Target scope。

在插件中选中结果，点击 Export browser check，把 HTML 保存到当前 demo/pages 目录。例如命名为 check.html，再访问 check.html。

本机两个不同端口属于不同 Origin，但相同 site。这个实验用于验证跨 Origin 读取流程，不能代替真实跨 site Cookie 条件验证。

所有 API 数据均为本地假数据，服务仅监听 127.0.0.1。
